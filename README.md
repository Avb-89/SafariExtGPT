# SafariExtGPT

**SafariExtGPT** — расширение для Safari на macOS, которое встраивает ChatGPT прямо в браузер и позволяет работать с содержимым веб-страниц без постоянного переключения между Safari и отдельным приложением ChatGPT.

## Идея

Создать нечто похожее на недавно почивший AtlasGPT. Есть расширение для хрома ChatGPT но он работает только с кодексом. Если кодекса на компьютере нет, работать расширение не будет. А мне так не хочется.

Расширение добавляет компактную боковую панель ChatGPT непосредственно в Safari. Модель автоматически получает необходимый контекст открытой страницы и может отвечать на вопросы о её содержимом.

Открыл страницу → открыл SafariExtGPT → спросил.

планируемые возможности:

SafariExtGPT сможет передавать ChatGPT контекст текущей вкладки:

- адрес страницы;
- заголовок;
- текст и структуру страницы;
- выделенный текст;
- содержимое редактируемых элементов;
- скриншот видимой области страницы;
- изображения, вставленные пользователем из буфера обмена.

Это позволит задавать вопросы вроде:

> О чём эта страница?

> Кратко перескажи эту статью.

> Объясни выделенный фрагмент.

> Найди здесь нужную мне информацию.

> Сравни эти характеристики.

> Что означает эта ошибка?

> Перепиши этот текст короче.

Без необходимости вручную копировать весь контекст в ChatGPT.



SafariExtGPT задуман не только для чтения страниц.

Если пользователь работает с текстовым полем или веб-редактором, ответ ChatGPT можно будет использовать непосредственно на странице.

Например:

- написать текст;
- исправить ошибки;
- перевести;
- изменить стиль;
- сократить;
- дополнить;
- заменить выделенный фрагмент;
- вставить готовый ответ в текущее поле.

При этом изменение содержимого страницы происходит только по явному действию пользователя (нажать insert).

В верхней части панели планируется быстрый доступ к диалогам:

- выбор текущего чата;
- создание нового чата;
- обновление текущего диалога;
- продолжение существующей беседы.

Одна из целей проекта — максимально приблизить работу с диалогами к обычному ChatGPT и, где это технически возможно, использовать серверные чаты вместо отдельной локальной истории расширения.

В поле сообщения можно будет вставлять изображения обычным `⌘V`.


Кроме того, расширение сможет использовать скриншот видимой области текущей веб-страницы как дополнительный визуальный контекст.


SafariExtGPT рассчитан на использование существующего аккаунта **ChatGPT / Codex**.

Авторизация выполняется через OpenAI OAuth в браузере.

Для работы расширения не предполагается необходимость отдельно создавать OpenAI Platform API Key и настраивать отдельную API-оплату.
